# FHZ 复合纸定制实验室

一个面向复合纸定制流程的纯静态网页演示，包含彼此独立的买家页面、商家后台和订单查询页面。项目不接入支付，也不依赖服务器、数据库或前端构建工具，可直接部署到 Cloudflare Pages。

## 页面与功能

| 路径 | 用途 |
| --- | --- |
| `/` | 角色入口与项目介绍 |
| `/buyer/` | 买家选择纸张规格、填写数量和收货信息、生成演示订单 |
| `/seller/` | 商家维护店铺、分类、选项、图片、价格和订单状态 |
| `/orders/` | 查询当前浏览器保存的订单 |

商家后台默认密码：`demo123`

### 买家端

- 选择纸张厚度、复合材质、层数、正面颜色、背面颜色和染色纹路。
- 支持商家新增的任意单选、多选或文本说明分类。
- 根据基础单价、选项加价、数量和杂费实时计算演示报价。
- 填写收货人、联系电话、地址、期望日期和备注后生成订单。
- 复制订单摘要，或在订单页查看状态与物流信息。

### 商家端

- 修改店铺名称、介绍、公告、联系方式、起订量、制作周期、基础单价和后台密码。
- 自由添加、编辑、排序、隐藏或删除分类。
- 为分类添加选项，并配置图片、简述、标签、加价与显示状态。
- 上传图片时在浏览器内自动压缩，降低 `localStorage` 占用。
- 演示接单、制作、发货、完成与取消流程。
- 导出、复制、导入 JSON 备份，或恢复默认演示数据。

## 本地预览

项目没有构建步骤。不要直接双击 HTML 文件，建议启动一个本地静态服务器：

```bash
python -m http.server 8080
```

打开：

```text
http://127.0.0.1:8080/
```

## 部署到 Cloudflare Pages

### Direct Upload

1. 下载或克隆本仓库。
2. 在 Cloudflare Pages 创建 Direct Upload 项目。
3. 上传**仓库根目录内的全部文件**，确保部署根目录直接包含 `index.html`。
4. 不需要填写构建命令，也不需要设置输出目录。

项目采用文件夹路由：

```text
/
/buyer/
/seller/
/orders/
```

仓库没有 `_redirects`，避免 Cloudflare Pages 的干净 URL 行为与自定义跳转规则形成循环重定向。

### Git 集成

连接本仓库后使用以下设置：

```text
Framework preset: None
Build command: exit 0
Build output directory: .
Root directory: 留空
```

## 数据说明

所有配置与订单都保存在浏览器 `localStorage`：

- 同一域名、同一浏览器中的买家和商家页面可以共享数据。
- 不同设备、不同浏览器或无痕窗口之间不会自动同步。
- 清理站点数据会删除订单和商家配置。
- 从旧版演示升级时，页面会尝试迁移 `composite-paper-toy.v1` 数据。
- 建议修改大量图片前先在商家后台导出 JSON 备份。

这是一个玩具型静态原型，不具备真实账号认证、云端订单、库存、支付、短信、物流接口或多人协作能力。

## 视觉方向

界面以克制的专业编辑风格为主，结合纸张行业适合的植物性自然色、纸张纹理和材料层叠意象。设计重点是：

- 高对比文本和明确的信息层级。
- 充足留白、细分隔线与较低阴影强度。
- 不使用固定底部操作条，避免遮挡内容。
- 商家表单通过标签页和弹窗分层，减少同屏元素数量。
- 桌面、平板和手机端均采用响应式布局。
